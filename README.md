# hugonotfound.fr

Bienvenue sur le dépôt de mon site web personnel ! Ce projet sert de portfolio pour présenter mes compétences, mes projets et me permettre d'être contacté.

Le site est construit avec des technologies web modernes pour offrir une expérience rapide et réactive.

## Technologies Utilisées

Ce projet a été développé en utilisant les technologies et outils suivants :

![Next.js](https://img.shields.io/badge/next.js-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)
![React](https://img.shields.io/badge/React-61DAFB?style=for-the-badge&logo=react&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=for-the-badge&logo=tailwind-css&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)


*   **Next.js**: Framework React pour le rendu côté serveur et la génération de sites statiques, offrant des performances optimisées.
*   **React**: Bibliothèque JavaScript pour la construction d'interfaces utilisateur interactives.
*   **Tailwind CSS**: Framework CSS utilitaire pour styliser rapidement et efficacement l'interface.
*   **TypeScript**: Sur-ensemble typé de JavaScript qui améliore la maintenabilité et la robustesse du code.

## Lancer le projet localement

Suivez ces instructions pour cloner le dépôt et exécuter le projet sur votre machine locale.

### Prérequis

Assurez-vous d'avoir les éléments suivants installés :

*   Node.js (version LTS recommandée)
*   pnpm (ou npm/yarn, mais pnpm est utilisé dans ce projet)

### Étapes

1.  **Cloner le dépôt :**

    ```bash
    git clone https://github.com/Hugonotfound/hugonotfound.fr.git
    ```

2.  **Naviguer dans le répertoire du projet :**

    ```bash
    cd hugonotfound.fr
    ```

3.  **Installer les dépendances :**

    ```bash
    npm install
    ```

4.  **Lancer le serveur de développement :**

    ```bash
    npm dev
    ```

5.  **Ouvrir dans le navigateur :**

    Le site sera accessible à l'adresse [http://localhost:5173](http://localhost:5173).

## Scripts Utiles

*   `npm dev`: Lance le serveur de développement.
*   `npm build`: Construit l'application pour la production.
*   `npm start`: Lance le serveur de production après avoir construit l'application.
*   `npm lint`: Exécute l'analyse du code (ESLint).
